# mybench 测试设计文档

> 状态：草案 v0.1（待完善）。目标：定义 `src/mybench.cu` 的测试设计、流程与口径，
> 供后续实现与评审。原始流程草稿见同目录 `test_flow.txt`。

## 1. 目标与范围

- 提供一个新的、结构清晰的 MoE mega kernel 基准程序 `mybench`，**每进程一张卡**，
  通过 `mpirun -np R` 启动（R 个进程 = R 个 rank）。
- 首期只做 **均衡模式（`--s 0`）** 的端到端 kernel 计时，输出跨 rank 的
  min/max/mean（`us/kernel`）。
- 不做：正确性数值对拍（后续可扩展）、不均衡 TK_INFO（`--s 1`，预留）。

## 2. 环境与启动方式

- 启动脚本：`test/1.mytest/run.sh -R 32 [...]`
- 实际命令：
  ```
  MACA_VISIBLE_DEVICES=0,...,31 \
  mpirun --allow-run-as-root --oversubscribe -np R \
      ./mybench --s 0 --tprs 1,4,16,32,64,128 --nodes 20 --replays 2
  ```
- 依赖：`megakernel.so`（`scripts/build.sh` 构建）、MACA ompi（`mpirun`）、MPI（`-lmpi`）。
- 约束（AGENTS.md）：单次测试 10s 内；kernel 内含超时断言；GPU 竞争需持锁。

## 3. 测试流程图

```
run.sh -R 32 -> mpirun -np R ./mybench
  main
    parse_args
    MPI_Init ; rank=g_mpi_rank ; R=g_mpi_size ; mcSetDevice(rank)

    [A] 每 rank 资源初始化（一次）
        sym = mcExtMallocWithFlags(Finegrained, sym_alloc) + memset
        lf  = mcMalloc ; rf = Finegrained + memset
        w1/w2 = mcMalloc + fill_weights_lane
        ffn_hidden / l2_out / y = mcMalloc + memset
        mcIpcGetMemHandle(sym) / (rf)
        MPI_Allgather(handle)  -> mcIpcOpenMemHandle(peer) -> mcDeviceEnablePeerAccess
        d_base_ptrs / d_rf_ptrs (H2D)
        MPI_Barrier

    [B] if --s 0（均衡模式）:  tprs = {1,4,16,32,64,128}
        foreach tpr in tprs:
            data_init(tpr)   # 填 x / topk_weights / topk_idx(均衡路由=make_routes Balanced)
            eager            # launch_full(a) × 1（预热）
            graph_capture    # BeginCapture -> launch_full(a) × nodes(=20) -> EndCapture
                             # -> mcGraphInstantiate
            MPI_Barrier
            warmup           # mcGraphLaunch(ex) × 2 ; sync
            measure          # event t0 -> mcGraphLaunch(ex) × replays(=2) -> event t1 ; sync
                             # us_per_kernel = (t1-t0)*1000/(nodes*replays)
            MPI_Allgather(us_per_kernel)
            rank0 打印 us_min / us_max / us_mean
        MPI_Barrier

    MPI_Finalize
```

## 4. 阶段详细设计

### 4.1 parse_args
| 参数 | 含义 | 默认 |
|---|---|---|
| `--s N` | 场景：0=均衡（首期），1=TK_INFO 不均衡（预留） | 0 |
| `--tprs L` | 逗号分隔 TPR 列表（`--s 0`） | 1,4,16,32,64,128 |
| `--nodes N` | 每张图的 kernel 节点数 | 20 |
| `--replays N` | 计时 replay 次数 | 2 |
| `--max-tokens M` | 槽容量（固定，供全部 TPR 复用） | 128 |
| `--tk-info F` / `--tk-launch N` | `--s 1` 用（预留） | - |
| `--quiet` | 只打印汇总行 | 0 |

### 4.2 MPI 初始化与句柄交换
- `rank = MPI_Comm_rank`，`R = MPI_Comm_size`；`mcSetDevice(rank)`。
- `mcIpcMemHandle_t` 为 80B POD；`MPI_Allgather(…, sizeof(mcIpcMemHandle_t), MPI_BYTE, …)`
  两次（sym、rf）。
- peer 打开后 `mcDeviceEnablePeerAccess`；构建 `d_base_ptrs`/`d_rf_ptrs` 设备数组。
- 所有 rank 完成后 `MPI_Barrier`。

### 4.3 data_init(tpr)
- `tokens = tpr`；`x[t][c] = (rank*37 + t*7 + c*3) & 0x3f`（确定性）。
- `topk_weights[i] = 1 + rank*0.25 + (i%7)*0.01`。
- `topk_idx = make_routes(RoutePattern::Balanced, rank, R, tpr)`（H2D 上传）。
- 清零：`src_index_table`、`barrier_slots`、`lf`、`rf`。

### 4.4 eager
- `fp8mega::launch_full(a, st)` 一次，`mcStreamSynchronize`。用于预热（可选做正确性）。

### 4.5 graph capture
- `mcStreamBeginCapture(st, ThreadLocal)` → `launch_full(a)` × nodes（每节点 = 一次
  full launch：mega + REDUCE）→ `mcStreamEndCapture` → `mcGraphInstantiate`。

### 4.6 warmup + measure
- warmup：`mcGraphLaunch(ex)` × 2 + sync + `MPI_Barrier`（跨 rank 对齐）。
- measure：`mcEventRecord(t0)` → `mcGraphLaunch(ex)` × replays → `mcEventRecord(t1)` → sync。
- 口径：`us_per_kernel = elapsed_ms * 1000 / (nodes * replays)`。

### 4.7 gather & 打印
- `MPI_Allgather(us_per_kernel)`；rank0 计算并打印 `us_min/us_max/us_mean`。
- 输出格式（每 TPR 一行）：
  ```
  R    TPR      us_min     us_max    us_mean
  32   1        xxx.xx     xxx.xx    xxx.xx
  ...
  ```

## 6. 验收标准（首期）

1. `test/1.mytest/run.sh -R 32` 正常退出（rc=0），每进程一张卡。
2. `--s 0` 输出 6 个 TPR 的 `us_min/us_max/us_mean`。
3. **与 `MX_NO_REUSE=1 ./bench --tprs 1,4,16,32,64,128` 在 ±3% 内一致**
   （已实测：mybench 与 bench 关复用后逐档差 ≤0.5%，TPR16 −3.6% 属噪声）。见下说明。
4. 单次命令 wall 时间可控（受 32 卡初始化与外部争用影响，目标 < 60s）。
5. 不修改现有 `bench.cu` 行为（新增文件 + build 目标）。

### 6.1 与 bench 默认口径的差异（重要）
- `bench` 的图默认开启**跨 graph 节点前序复用**（`skip_prologue=2`，节点 1..N 跳过
  ROUTE/PUBLISH/XBAR），比全 prologue 快 ~8~16%。
- `mybench` 每节点跑**完整 prologue**（更贴近生产：生产未开 CUDA graph，每条 launch
  都要跑全前序）。故 mybench 应与 `MX_NO_REUSE=1 ./bench` 对齐，而非 bench 默认。
- 实测（R=32, nodes=20, replays=2, max_tokens=512）：
  | TPR | bench(默认,复用) | bench(MX_NO_REUSE=1) | mybench |
  |---:|---:|---:|---:|
  | 1 | 266.4 | 306.4 | 304.3 |
  | 4 | 283.7 | 318.9 | 320.4 |
  | 16 | 340.5 | 361.3 | 348.4 |
  | 32 | 442.3 | 476.1 | 476.5 |
  | 64 | 587.9 | 655.3 | 657.8 |
  | 128 | 966.5 | 1047.1 | 1046.9 |

## 8. 关键接口速查

- 常量（`common.cuh`）：`kEPR=8, kTopk=8, kHidden=6144, kIntermediate=2048, kGrid=32, kRing, kM=16`。
- 布局（`host_layout.cuh`）：`ProdLayout L = compute_layout(R, max_tokens, kTopk, kHidden, kIntermediate, win_cap + win_pad)`；`CHECK` 宏。
- 路由（`bench_check.cuh`）：`make_routes(RoutePattern::Balanced, rank, R, tokens)`。
- 发射（`megakernel.h`）：`fp8mega::MegaLaunchArgs`；`launch_full(a, st)`；`fill_weights_lane(...)`。
- MPI：`g_mpi_rank/g_mpi_size`、`MPI_Allgather`、`MPI_Barrier`（参照 `bench.cu` 的 `run_aligned_mpi`）。
